# Notes Management System

A full-stack Notes Management Application built using the MERN stack (MongoDB, Express.js, React.js and Node.js).

## Features

- User registration and login with JWT authentication
- Protected routes and ownership-based authorization
- Create, read, update and delete notes (CRUD)
- Search notes
- Pagination for managing notes
- RESTful API integration
- Centralized error handling and input validation

## Tech Stack

**Frontend:** React.js, JavaScript, Axios, React Context API, CSS

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT

**Tools:** Git, GitHub, VS Code, Hoppscotch

## Project Repositories

- **Frontend:** https://github.com/Samiksha-d-20/notes-management-system-frontend
- **Backend:** https://github.com/Samiksha-d-20/notes-management-system-backend

## Architecture

The React frontend communicates with the Express.js backend through REST APIs. MongoDB stores user and note data, while JWT authentication secures user-specific resources.
